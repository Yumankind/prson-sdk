Form & mouse binding

After signing in with Prson, the page can ask the wallet to fill any input — single field, whole form, or phone-as-cursor. Open the wallet, scan the QR, then try each demo below.

1. Sign in required first

Click sign in — the QR appears in a centred modal. Press Esc or click outside to cancel. Once the wallet delivers the credential, the modal closes and the buttons in the sections below become enabled.

Signed in

2. bindInput — single field

A single input with a label + validation constraints. The wallet opens a sized keyboard, the user types on their phone, and the value lands in the page on send.

3. bindForm — multi-step form

A <form> with several fields. The wallet opens one drawer with Prev / Next / Send navigation and fills every field at once on Send. bindForm also fires requestSubmit() when the bind target is a <form>. 


      


      
      

        
4. bindMouse — phone as cursor

        

          Turn the phone into a touchpad (mode: "touch")
          or a gyro-driven magic wand (mode: "magic"). A
          virtual cursor appears on the page and follows the phone
          input until the user closes the wallet drawer.
        

        

          
          
        

      


      
      

        
5. File input — phone-as-camera-and-gallery

        

          Focus this <input type="file"> with the
          phone's remote-control banner up. The wallet opens its own
          file picker (Camera / Photos / Files), filters by the
          accept attribute, and streams the chosen bytes
          back over the encrypted data channel — chunked, ack-tracked,
          SHA-256-verified before assignment. Memory profile stays
          flat on both peers: only one chunk worth of bytes lives in
          RAM at a time.
