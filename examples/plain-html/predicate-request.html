Predicate request demo

Sign in with the Prson wallet, then request a signed predicate (e.g. age_gte_18) in whichever wire format your verifier speaks. The credential is verified by the companion Express server in ../express-verifier.

1. Sign in

Click below; the SDK pops a modal QR. Scan it in the Prson wallet to complete the handshake.

2. Request a predicate

The wallet pops a drawer asking the user to approve disclosing this predicate. The signed result comes back over the same encrypted data channel that carried sign-in.

3. Wallet reply

Raw payload returned by session.request() — shape depends on the format you picked.
